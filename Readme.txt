---------------------------------------------------------- LASER DISPLACEMENT SENSOR ----------------------------------------------------------

This project implements a closed-loop control and monitoring system for a piezo actuator using a laser interferometer for displacement measurement. A microcontroller acquires sensor data, a Python program processes and stabilizes the motion via PID, and a Moku device generates the control waveform.

---------------------------------------------------------- System Architecture ----------------------------------------------------------
1. Hardware

- HP/Agilent 5517 – laser aperture for interferometry

- Piezo actuator – displacement stage being controlled

- Microcontroller – generates signals, reads displacement feedback, communicates via MQTT

- Moku device – waveform generator and monitoring interface

- Interferometer – measures displacement with sub-nanometer resolution, displayed via Micro Measurement Display software

2. Software

- moku_device.py – waveform generation and control of the Moku hardware

- controller.py – PID controller, low-pass filter, and data processing routines

- mqtt.py – MQTT communication bridge with VB.NET GUI and microcontroller

- monitor.py – real-time sine health monitoring and quality checks

- parse_data.py – utilities for logging and displacement calculation

- main.py – orchestrates workflow, runs PID loop, manages buffers, and outputs status

---------------------------------------------------------- Workflow ----------------------------------------------------------

1. Signal Generation

- A sine wave is generated by the Moku device with configurable amplitude, frequency, and offset.

- The PID controller dynamically adjusts the DC offset to correct displacement.

2. Feedback Loop

- The microcontroller captures displacement data from the piezo actuator.

- Data is transmitted via MQTT to Python, parsed, and stored in rolling buffers.

3. Monitoring

- Data is fitted against a reference sine using SineMonitor.

- Status output:

    @ [SINE OK] – signal matches expected sinusoid within thresholds (R² ≥ 0.90, RMSE ≤ 0.20, amplitude ≥ 0.3).

    @ [SINE UNKNOWN] – waveform deviates (e.g., tapping disturbances, hysteresis effects, voltage clipping).

---------------------------------------------------------- Notes ----------------------------------------------------------

- Closed-loop PID ensures stable displacement and prevents integral wind-up
- Real-time sine validation verifies waveform quality and fit metrics
- Safety clamps prevent exceeding piezo drive limits (±5 V hardware range, adjusted by amplitude)
- Disturbance handling: logs [SINE UNKNOWN] when external effects (e.g., tapping the stage) disrupt sinusoidal motion.

---------------------------------------------------------- Testing & Validation ----------------------------------------------------------

1. Baseline Test
- Run system with no disturbances. Expect continuous [SINE OK].

2. Disturbance Test
- Lightly tap the platform. Expect temporary [SINE UNKNOWN] until system recovers.

3. Frequency Sweep
- Change waveform frequency to 0.5 Hz or 2 Hz. Monitor should still confirm [SINE OK].

4. Offset Sweep
- Drive offset toward ±2.5 V (for 5 Vpp amplitude). System should operate without coercion errors.
